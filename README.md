# 상식 1000제

전 분야 상식 퀴즈. 문제 은행 1,024문항(20개 분야)에서 매번 20문항을 무작위로 출제합니다.

- 한 분야에서 최대 2문항까지만 출제해 여러 분야가 고르게 섞입니다.
- 최근에 푼 문항은 뒤로 밀려 새 문항이 먼저 나옵니다(브라우저에 저장).
- 보기를 고르면 그 문항의 정답률과 보기별 선택 비율을 바로 보여 줍니다.
- 결과 화면에서 분야별 성적, 전체 해답, 전체 응시자 중 상위 몇 %인지를 보여 줍니다.
- `stats.html`에서 점수 분포와 문항별 정답률(어려운 순·쉬운 순·분야별·검색)을 볼 수 있습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 퀴즈 본체 |
| `questions.js` | 문제 은행 1,024문항 |
| `stats.html` | 전체 응시 통계·문항별 정답률 페이지 |
| `config.js` | 통계 서버(Supabase) 주소와 공개 키 |
| `stats-api.js` | 통계 서버와 주고받는 공통 코드 |
| `supabase_setup.sql` | Supabase에서 한 번 실행하는 DB 설정 |

## 통계 켜기

1. supabase.com에서 프로젝트를 만듭니다.
2. SQL Editor에서 `supabase_setup.sql` 전체를 붙여 넣고 실행합니다. (여러 번 실행해도 안전합니다. 파일이 바뀌면 다시 실행하세요.)
3. 프로젝트의 URL과 Publishable key를 `config.js`에 넣습니다.

`config.js`를 비워 두면 통계 없이 퀴즈만 동작합니다.

### 점수 기록 방식

- 판을 시작하면 서버가 판 번호를 주고, 답을 고를 때마다 그 판에 저장합니다. 점수는 서버에 쌓인 답으로 계산합니다.
- 중간에 '그만두기'를 누르면 바로, 창을 닫고 떠나면 마지막 답 뒤 30분이 지나면 그때까지 맞힌 개수로 기록합니다 (안 푼 문항은 오답). 한 문제도 안 푼 판은 기록하지 않습니다.
- 새로고침하거나 다시 들어오면 같은 판을 이어서 풀 수 있고, 이미 고른 답은 바뀌지 않습니다.
- 순위는 점수 → 끝까지 푼 판 우선 → 걸린 시간 순입니다.

### 랭킹전

- 닉네임을 입력하고 10·20·30·40문항 중 하나를 골라 문항당 5초(20문항 100초) 안에 몇 개 맞히는지 겨룹니다.
- 문항 수마다 하루(한국 시간) 한 번 도전할 수 있습니다. 같은 기기 1회, 같은 접속 주소는 하루 3회까지입니다.
- 문제는 도전할 때마다 무작위로 뽑습니다(한 분야에서 10·20문항은 1개, 30·40문항은 2개까지).
- 제한 시간은 서버 시각으로 재고, 시간이 끝나거나 그만두면 그때까지 맞힌 개수로 기록합니다(그만두면 제한 시간을 다 쓴 것으로 칩니다).
- 순위는 맞힌 개수 → 걸린 시간 순이며, 역대 1~3위는 명예의 전당(통계 페이지)에 남습니다.
